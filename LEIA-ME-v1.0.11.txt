ATENCAO / LIMITACOES
- A v1.0.10 usa saldo de estoque ATUAL, nao necessariamente o mesmo saldo
  da hora da impressao do romaneio. Portanto status permanece P.
- O SQL original nao restringe TIPMOV='P'; validar divergencias de documentos.
- O SQL original pode tratar unidades mistas; bloqueio implementado no resumo.
- Nao existe liberacao administrativa, retomada, cancelamento, historico ou
  leitura de barras nesta versao. Nao usar para liberar cargas em producao.
- O acesso direto as tabelas AD_CONF_CARGA_PREV deve ser restrito; nunca expor
  dados detalhados no JavaScript da conferencia cega.
- Erros no metodo transacional propagam excecao para rollback pelo container EJB.
- O codigo ainda precisa de build no SDK e teste de integracao Oracle local.
